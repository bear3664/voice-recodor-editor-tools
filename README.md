# 録音・音声編集ツール

ブラウザだけで動く、**録音ツール**と**音声エディター**のセットです。ビルドや依存パッケージ、サーバーは不要で、すべて単体の HTML ファイルで構成されています。録音・編集した音声は PC のブラウザ内で処理され、外部サーバーへ送信されません。

## 構成

| ファイル | 内容 |
| --- | --- |
| `index.html` | トップページ。2つのツールへの入口と、使い方の流れ・注意事項 |
| `browser-recorder.html` | ブラウザ音声レコーダー（タブの音声＋マイクを録音） |
| `audio-editor.html` | 音声エディター（マルチトラック編集・書き出し） |

## 使い方

1. リポジトリを取得し、`index.html` をブラウザで開く（GitHub Pages などで静的配信してもOK）。
   - タブ共有・マイクの利用には安全なコンテキスト（`https://` または `localhost`）が必要な場合があります。`file://` で動かない場合は簡易サーバーを使ってください。
     ```sh
     python3 -m http.server 8000   # → http://localhost:8000/
     ```
2. 「ブラウザ音声レコーダー」で録音し、ダウンロード。
3. 「音声エディター」にファイルをドラッグ＆ドロップして編集。
4. WAV または MP3 で書き出し。

## 対応ブラウザ

- **PC 版の Google Chrome / Microsoft Edge**（タブ音声の録音に必須）。
- Firefox・Safari ではタブ音声を録音できません。エディター単体の動作も Chrome / Edge を推奨します。

## ブラウザ音声レコーダー (`browser-recorder.html`)

ブラウザのタブで再生されている音声（会議、動画、配信など）を録音します。

- **タブ音声の録音**：録音ボタンを押すと共有ダイアログが開くので、対象タブを選び「**タブの音声も共有する**」をオンにします（`getDisplayMedia`）。オフだと録音できずエラー表示になります。
- **マイクの重ね録り**：マイクをオンにすると自分の声もミックスして録音できます（エコー除去・ノイズ抑制・自動ゲイン付き）。録音中のオン/オフ切り替えも可能です。
- **音量調整**：タブ・マイクそれぞれ 0〜150% のスライダーと、レベルメーター付き。
- **音質プリセット**

  | 設定 | 内容 | 目安サイズ |
  | --- | --- | --- |
  | 高音質 | ステレオ・192kbps | 約 1.4 MB/分 |
  | 標準（初期値） | ステレオ・96kbps | 約 0.7 MB/分 |
  | 長時間向け | モノラル・48kbps | 約 0.36 MB/分 |

- **録音一覧**：録音ごとに時刻・長さ・サイズを表示し、その場で試聴、ダウンロード、削除ができます。ファイル名は `recording-YYYYMMDD-HHMMSS.webm`（ブラウザによって `.ogg` / `.m4a`）。
- タブの共有を停止すると録音も自動的に終了します。録音中にページを閉じようとすると確認が出ます。

## 音声エディター (`audio-editor.html`)

複数トラックを重ねて編集できるタイムライン型のエディターです。

### 読み込み

- 音声ファイル（`audio/*`、mp4/webm 動画の音声も可）を、ドロップまたは「音声ファイルを選ぶ」で読み込み。複数同時選択可。
- 読み込むごとに新しいトラックになります。
- **読み込み品質**
  - 軽量（初期値）：16kHz・モノラルに変換。メモリ/時間を大きく節約でき、文字起こし用途には十分。**書き出し音質も同じになります。**
  - 標準：元の音質のまま。音楽向け。1時間超の録音では動作が重くなることがあります。

### 編集機能

| 分類 | 機能 |
| --- | --- |
| 再生 | 再生/停止、選択範囲の再生、先頭へ、±5秒移動、再生位置スライダー、ルーラーのクリックで位置指定 |
| 範囲編集 | 削除（詰める）、無音にする、範囲だけ残す、再生位置で分割 |
| 音量 | フェードイン/アウト、範囲の音量（dB）、トラックの正規化 |
| クリップ操作 | コピー / 切り取り / 貼り付け、ドラッグまたは秒数指定で移動（吸着：他クリップの端・再生位置・0秒、Alt で一時無効）、別トラックへの移動 |
| トラック | 追加（空トラック含む）、名前変更、音量、ミュート、削除 |
| 速度・ピッチ | 速度 0.25〜4 倍（ピッチ維持 / ピッチも変化）、ピッチ −12〜+12 半音、逆再生 |
| EQ | 低域・中域・高域 ±24 dB、ローカット（Hz） |
| ノイズ除去 | ノイズだけの区間（0.2秒以上）を「ノイズ見本」に登録 → 強さ（弱/中/強）を選んで除去 |
| 履歴 | 元に戻す / やり直す |

- 速度・ピッチ・EQ・ノイズ除去などは、範囲を選ぶとその範囲のみ、未選択ならトラック全体に適用されます。
- 波形のドラッグで範囲選択、ズーム（拡大）スライダーあり。

### キーボードショートカット

波形（キャンバス）をクリックしてフォーカスしてから使います。

| キー | 動作 |
| --- | --- |
| Space | 再生 / 停止 |
| Delete / Backspace | 選択範囲を削除（詰める） |
| S | 再生位置で分割 |
| ← / → | 5秒戻る / 進む（Shift で1秒） |
| Home | 先頭へ |
| Ctrl(⌘)+Z / Ctrl(⌘)+Shift+Z, Ctrl+Y | 元に戻す / やり直す |
| Ctrl(⌘)+C / X / V | コピー / 切り取り / 貼り付け |

### 書き出し

- ミュート中のトラックを除いたミックスを書き出します（トラック音量を反映）。
- 形式：**WAV** / **MP3 128kbps** / **MP3 192kbps**。ファイル名は `mix-YYYYMMDD-HHMMSS.wav|mp3`。
- 「書き出し時に音量を揃える」で、ピークを約 −1 dB に正規化できます。
- MP3 の初回書き出し時のみ、エンコーダー [lamejs](https://github.com/zhuker/lamejs) 1.2.1 を cdnjs から取得します（音声は送信されません）。

## プライバシーと注意事項

- 録音・編集データは外部に送信されません。通信は Google Fonts（Zen Kaku Gothic New）の読み込みと、MP3 書き出し時の lamejs 取得のみです。
- **ページを閉じる・再読み込みすると、録音や編集内容は消えます。** 必要なものは必ずダウンロード/書き出ししてください。
- 文字起こしなどの音声解析は、ご自身が信頼できるサービスで行ってください（本ツールには含まれません）。
- 他人の会話や著作物を録音する際は、法令・利用規約・相手の同意に配慮してください。

## 技術メモ

- 純粋な HTML / CSS / JavaScript（フレームワーク・ビルド不要）。
- 録音：`getDisplayMedia` / `getUserMedia` / Web Audio API / `MediaRecorder`（WebM Opus を優先、非対応時は ogg / mp4 にフォールバック）。
- 編集：Web Audio API、`OfflineAudioContext`、WSOLA による速度変更、FFT ベースのスペクトル減算ノイズ除去。
- ライトモード/ダークモードに自動対応。
